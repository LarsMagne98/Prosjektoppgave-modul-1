# Jeg har valgt prosjektalternativ: I. Analyse av hendelseslogg.

Programmet starters ved å skrive "dotnet run" i konsollen.
Du får opp flere alternativer og velger et alternativ ved å skrive "1", "2", "3", "4" eller "5" og trykker enter.

Programmet leser av en fil med en logg og gir informasjon videre til brukeren basert på hva brukeren ønsker å vite.
Du kan dele opp loggen basert på level (INFO, WARNING, ERROR), eller source (Payments, Checkout, Inventory).
Du kan også skrive ut statestikk av loggen til en Raport fil.
